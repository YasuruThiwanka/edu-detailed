# SCT — Study Challenge Tracker

This is the front-end for the Study Challenge Tracker (SCT) application.

## How to Run

Open the `.html` files in your browser to view the pages.

## How to Extend

- Edit the `assets/css/styles.css` file to change the appearance.
- Edit the `assets/js/*.js` files to modify the application logic.
- The mock data is managed in `assets/js/store.js`.

## How to Integrate

The application uses `data-api-*` attributes in the HTML to mark elements that will be connected to a backend API. Replace the mock data handling in `assets/js/store.js` with `fetch` calls to your API endpoints.
